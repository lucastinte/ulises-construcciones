# Ulises Construcciones – Panel de Presupuestos

Aplicación web estática, responsiva y lista para usarse en campo para capturar la información de presupuestos, cronogramas y notas de proyectos de construcción.

## 🚀 Cómo usar

1. Descarga este repositorio o clónalo en tu equipo.
2. Abre el archivo `index.html` en tu navegador preferido (no requiere instalación adicional).
3. Captura la información del proyecto, agrega partidas y actividades según sea necesario.
4. Utiliza el botón **"Descargar presupuesto"** para obtener una copia en formato JSON con todos los datos capturados.
5. La información se guarda automáticamente en el navegador (localStorage). Puedes limpiar todo con el botón **"Limpiar todo"**.

## ✨ Características principales

- Diseño responsivo pensado para escritorio, tablet y móvil.
- Secciones separadas para materiales, mano de obra, subcontratos y otros costos con totales automáticos.
- Resumen financiero con cálculo de impuestos configurable.
- Cronograma de actividades editable con responsables y fechas.
- Área para notas, alcances y enlaces a documentación de respaldo.
- Copia de seguridad local automática y exportación descargable.
