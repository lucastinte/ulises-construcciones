    ¿Cómo preparo el archivo?

    Para agregar o actualizar materiales, siempre subí un archivo CSV. Si tu fuente es un Excel, convertí las columnas de nombre y precio con el siguiente prompt (copialo en ChatGPT u otra IA): 

    Convierte esta tabla a CSV con columnas nombre,precio.
- Cada nombre debe ir entre comillas dobles.
- Elimina símbolos de moneda y usa punto como separador decimal (ej: $ 83.644,53 → 83644.53).
- Descarta filas sin precio.
- Responde solo con el CSV dentro de ```csv ... ```.
A continuación pego las filas (nombre | precio):
<pega aquí tus datos>
    1. Copia las columnas de nombre y precio desde tu hoja original.
    2. Pega ese contenido en el prompt, descarga el CSV que devuelve y selecciónalo en este formulario.
    3. Presiona “Importar” para que el catálogo se actualice.
    4. Usa la tabla inferior para buscar, editar o eliminar cada material.
